# QA Bench (phase 1: smoke + covert) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `just qa <suite>` runs scripted test cases in the real game on a copy of the real run's
save, checks each against independent evidence, writes a pass/fail table, and puts the real run back.

**Architecture:** Python package `parley/qa/` (cases, checker, runner) drives the running game through
the bridge's existing `control.txt` (`lua <line>` runs one Lua line; result logged as
`control: lua -> ...`). A small `M.qa` table in the bridge holds the setup helpers (spawn, teleport,
skill, load) so each control line is one call. The QA game is the real save loaded under its own
`game_id` (`qa-<suite>`) with a `script:` seat; no new campaign, no menu clicks. The real run's
newest save is copied to a kept name first; restore = `M2TWEOP.loadGame(kept)`.

**Tech Stack:** Python 3 (pydantic, pytest), Lua 5.1 bridge under M2TWEOP, bash + just.

**Spec:** `docs/superpowers/specs/2026-10-30-test-bench-design.md` (approved; see "Settled").

## Global Constraints

- Command is `just qa <suite|all>` and `just qa-restore`; module `parley/qa/`; results `runs/qa/`.
- `OrderResult.ok` alone never passes a case; every case has ≥1 independent check.
- A run refuses to start unless `<save_dir>/parley_keep_<real_game_id>.sav` exists and equals the
  newest real save (size + sha256).
- During a run the real loop, bot and crash-watch are stopped; the QA run starts no Discord bot.
- A crash during a run aborts and restores; never relaunch into the QA game.
- Smoke cases run first; a failed smoke case aborts the run.
- EOP calls one per control line / tick (memory eop-events-one-at-a-time); every helper is pcall'd
  and logs `qa: <helper> ok|failed: <detail>`.
- One-line justfile recipes; logic in `scripts/qa.sh` and `parley/qa/`.
- Bridge facts: control file `<turn_root>/control.txt`, polled every ~2 s, read then deleted
  (`lua/parley_bridge.lua:3845`); config `<turn_root>/bridge.txt`, re-read every tick
  (`config()`, `:61`), written by `Orchestrator.publish_bridge_config()` (`parley/orchestrator.py:193`);
  `script:` turn keys are absolute game turns (`parley/seats/script.py:66`).

## Review Focus

1. **The keep copy is stale** (real run advanced after the copy) → refuse to start, say why. Test in Task 4.
2. **Control line never answered** (bridge not loaded, game on menu) → each control call times out
   (30 s) with a clear error; the run aborts and restores. Test in Task 2.
3. **Restore with the game not running** (crashed mid-run) → `qa-restore` relaunches (Continue),
   then loads the kept save by control line, then restarts the real loop and crash-watch. Test in Task 4.
4. **Log lines from before the run match an expectation** → the checker only reads log bytes written
   after the case started (byte offset). Test in Task 3.
5. **Spy mission never succeeds inside the cap** → case is `inconclusive`, never `pass`. Test in Task 3.

### Task 3: Cases and checker (`parley/qa/cases.py`, `parley/qa/checker.py`)

**Files:** Create both; suites `games/qa/smoke.toml`, `games/qa/covert.toml`; Test `tests/test_qa_checker.py`

**Interfaces:**
- Produces:
  - `class Case(BaseModel)`: `name: str`, `setup: list[str]` (Lua lines, `$x/$y` from `targets`),
    `orders: dict[int, list[dict]]` (relative turn → orders, made absolute at run time),
    `expect: list[Expect]`, `max_turns: int = 3`, `seat: str = "script"`, `directive: str = ""`.
  - `class Expect(BaseModel)`: `log: str | None` (regex on bridge log after the case's offset),
    `state: str | None` (dotted path into the next state.json, e.g. `agents[name=QA Spy].x`),
    `equals: str | int | None`, `order_ok: bool | None`. A case passes only if every expect holds and
    at least one is `log` or `state`.
  - `class Suite(BaseModel)`: `name`, `faction`, `cases: list[Case]`; `load_suite(path) -> Suite`.
  - `check(case, log_text_since_offset: str, state: dict | None, results: list[dict]) -> Verdict`
    where `Verdict = Literal["pass", "fail", "inconclusive"]` plus `evidence: str`.
- Suites (exact content is the builder's, these cases are required):
  - smoke: `spawn_agent` (evidence: the spy in next `state.json` agents at x,y), `teleport`
    (`M.qa.where` result equals target or adjacent), `playtest funds` (log `playtest funds: england topped up`),
    `load_save` round trip is NOT a case: it is proven by the runner's restore (Task 4).
  - covert: `spy_report_closed` (#255: spawn a max-skill spy next to a foreign settlement,
    order `spy`; pass on log `closed the spy report after england's mission`; inconclusive if
    `agent mission: england: .*spying: not successful` every turn up to max_turns),
    `assassinate`, `sabotage` (pass on `agent mission: england: .*<kind>:` log line + agent_results).

### Task 4: Runner, park/restore, recipes (`parley/qa/runner.py`, `scripts/qa.sh`)

**Files:** Create both; Modify `justfile` (+`qa suite`, `qa-restore`); Test `tests/test_qa_runner.py`

**Interfaces:**
- Consumes: `Control` (Task 2), `load_suite`/`check` (Task 3), `M.qa.*` (Task 1),
  `parley.saves` newest-save logic (`parley/saves.py:7-19`).
- Produces: `python -m parley.qa run <suite|all> --real games/local/<name>.toml` and
  `python -m parley.qa restore --real ...`; report `runs/qa/<date>-<suite>.md`; lock
  `<turn_root>/qa.lock` (JSON: real game_id, kept save path, started_at).

Run sequence: (1) refuse if lock exists; (2) copy newest real save to `parley_keep_<id>.sav`, verify
sha256; (3) write lock; (4) stop real loop/bot (`scripts/game.sh stop`) and crash-watch;
(5) start the QA loop (`parley run` on a generated `games/local/qa-<suite>.toml`: `game_id=qa-<suite>`,
the suite faction on `script:` with the case orders made absolute from the current turn,
`playtest_funds`, autoplay on, no bot); (6) smoke suite, then the suite: per case record the log
offset, run setup lines, let autoplay end turns until every expect is decided or `max_turns`;
(7) write the report; (8) restore: stop QA loop, `M.qa.load(kept)`, wait for `bridge reloaded`/turn
line, restart real loop+bot and crash-watch, delete lock. Any exception or a game exit → restore.
